# Documentación funcional para el dueño: Catálogo de Productos

Este backend gestiona todo el catálogo de productos, categorías, subcategorías y marcas de tu negocio. Permite administrar y consultar la información de los productos que vendes, así como organizarla de forma flexible y profesional.

## ¿Qué puedes hacer con este backend?

### 1. Gestionar productos
- **Crear, editar y eliminar productos**: Puedes dar de alta nuevos productos, actualizar sus datos (nombre, descripción, precio, stock, imágenes, etc.) o eliminarlos si ya no los vendes.
- **Asociar productos a categorías, subcategorías y marcas**: Cada producto puede pertenecer a una categoría (ej: Electrodomésticos), una subcategoría (ej: Lavadoras) y una marca (ej: Samsung).
- **Controlar stock y visibilidad**: Puedes indicar el stock disponible y si el producto está activo o no para la venta.

### 2. Organizar el catálogo
- **Crear y editar categorías y subcategorías**: Organiza los productos en categorías principales y subcategorías para facilitar la búsqueda y navegación.
- **Gestionar marcas**: Da de alta las marcas que vendes y asócialas a los productos correspondientes.
- **Ordenar y activar/desactivar**: Puedes definir el orden de aparición y activar/desactivar categorías, subcategorías y marcas.

### 3. Consultar y buscar productos
- **Búsqueda avanzada**: Filtra productos por nombre, categoría, subcategoría, marca, precio, stock, estado, etc.
- **Paginación y ordenación**: Consulta los productos por páginas y ordénalos por nombre, precio, fecha, etc.
- **Ver detalles completos**: Accede a toda la información de cada producto, incluyendo imágenes y relaciones.

### 4. Seguridad y control
- **Acceso restringido**: Solo usuarios autenticados y con permisos de administrador pueden crear, editar o eliminar productos, categorías y marcas.
- **Integridad de datos**: No se pueden eliminar marcas si están asociadas a productos, evitando errores en el catálogo.

## ¿Para qué sirve?
- Mantener tu catálogo siempre actualizado y bien organizado.
- Facilitar la gestión de productos, marcas y categorías desde un solo lugar.
- Permitir búsquedas rápidas y precisas para ventas, inventario o integración con la web/app.
- Preparar tu negocio para crecer, añadiendo nuevas categorías, marcas o productos fácilmente.

## ¿Qué NO hace?
- No gestiona ventas, clientes ni pagos (solo catálogo).
- No almacena imágenes, solo guarda las URLs (las imágenes se suben a un servicio externo).
- No tiene interfaz gráfica: se gestiona desde aplicaciones conectadas (web, móvil, Postman, etc.).
